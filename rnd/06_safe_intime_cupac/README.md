# Исследование допустимости признаков периода эксперимента для повышения точности оценки эффекта

Годовой отчёт № 10, каталог репозитория № 06. Проверяли, можно ли повысить точность оценки полного эффекта пилота за счёт данных, собранных после начала воздействия. На синтетике с известным эффектом сравнили последовательные корректировки. На открытых данных проверили признаки, собранные до пилота.

С ДИЭ обсуждаем, как отбирать признаки, измеренные после воздействия: по каким данным и на каком основании признак можно допустить к оценке полного эффекта пилота.
